# 打卡助手

一个 Windows 桌面习惯打卡软件。**双击即用，无需安装**：不需要 .NET SDK、不需要 Python、不需要 Node，也不联网。

![界面预览](预览.png)

---

## 快速开始

双击 **`打卡助手.exe`** 即可。

第一次打开时习惯列表是空的，点击左下角 **「＋ 新建习惯」** 添加第一个习惯，然后点右上角的 **「今日打卡」** 按钮即可打卡。

### 系统要求

- Windows 10 / 11（x64 或 x86 均可）
- .NET Framework 4.8 —— Windows 10 1903 以后与 Windows 11 全部自带，通常无需额外安装

---

## 功能

| 功能 | 说明 |
|---|---|
| **多习惯管理** | 新建、改名、换色、删除；每个习惯独立记录与统计 |
| **今日打卡 / 取消** | 一键切换。当天已填写心情或备注时会先确认，避免误删 |
| **备注与心情** | 每天可写一段备注，并从 5 档手绘表情中选一个心情；再点一次可取消 |
| **坚持统计** | 当前连续、最长连续、累计打卡、本月完成率 + 最近 30 天条带 |
| **日历热力图** | 月历视图。「本习惯」模式看单项目打卡；「全部习惯」模式按当天完成比例显示颜色深浅 |
| **补打卡** | 直接点击日历上任一过去/今天的日期即可补打卡或取消 |
| **自动保存** | 每次操作即时落盘，备注输入 1.5 秒防抖后保存 |

### 操作要点

- 左侧习惯列表：单击选中，**双击改名**，↑ ↓ 键切换，滚轮滚动
- 日历：`‹` `›` 翻月，点「回到本月」跳回当月，右上角胶囊切换「本习惯 / 全部习惯」
- 未来日期置灰不可点击；今天有描边
- 日历格上的标记：右上角小圆点 = 当天心情颜色，右下角小三角 = 当天写了备注

## 数据保存在哪里

默认保存在**程序所在目录**下的 `数据` 文件夹里：

```
<打卡助手所在文件夹>\数据\data.json
```

例如程序放在 `D:\打卡助手\`，数据就是 `D:\打卡助手\数据\data.json`。

这样整个文件夹拷走就能带走数据，也不会再遇到 C 盘 `%APPDATA%` 那种
「对路径 … 的访问被拒绝」的权限问题。界面底部会实时显示当前数据文件路径。

界面上点右下角 **「打开数据文件夹」** 可直接定位（并尽量选中 `data.json`）。

> **受限环境说明**：某些沙箱 / 远程会话里，新启动的 `explorer.exe` 会以
> `0xC0000142`（DLL 初始化失败）挂掉。软件的处理是：用自己的错误模式**压掉
> Windows 的原始错误框**，并异步检查子进程退出码；一旦失败就弹出一个把
> **路径预先选中**的对话框（不依赖剪贴板 API，直接按 Ctrl+C 即可），
> 粘贴到资源管理器地址栏就能打开。设置对话框里另有 **「复制数据路径」** 按钮。
>
> 踩过并**已废弃**的两种做法（源码注释里有记录）：
> `UseShellExecute = true`（启动被委托给外壳，压不住系统弹窗），
> 以及 `SHOpenFolderAndSelectItems` / `Shell.Application.Explore`
> （实测要花上百秒、还会卡死界面）。
>
> **如果在你机器上始终打不开**：到「设置」里取消勾选
> 「打开数据文件夹时，先尝试启动资源管理器」。之后点击就只显示路径，
> 不会再产生任何失败的进程或系统提示。

## 设置：自己挑保存位置

点右下角 **「设置」** 可以随时更换保存位置：

- **选择文件夹…** —— 挑任意文件夹，可以是别的盘
- **恢复默认位置** —— 回到程序目录下的 `数据` 文件夹
- **打开所在文件夹** —— 定位到当前选中的位置
- **复制数据路径** —— 把 `data.json` 的完整路径放进剪贴板
- **「打开数据文件夹时，先尝试启动资源管理器」** —— 见下方受限环境说明；
  如果你的机器上打不开，**把这个勾去掉**，点按钮就直接显示已选中的路径，
  不再做无谓的尝试

换位置时**不会悄悄丢数据**，程序会分两种情况明确询问你：

| 目标文件夹的情况 | 会问你什么 |
|---|---|
| 里面还没有 `data.json` | 「是否把当前的数据复制到新位置？」（推荐选「是」） |
| 里面已经有 `data.json` | 「使用该文件夹现有的数据」还是「用当前数据覆盖它」 |

选好的位置记在**程序目录下的 `config.json`**：

```json
{ "dataPath": "D:\\打卡助手\\数据\\data.json" }
```

`dataPath` 也可以写相对路径（相对程序目录），这样整个文件夹换台电脑依然能用。

**路径优先级**：命令行 `--data` > `config.json` > `程序目录\数据\data.json`。
如果配置的位置不可写，软件启动时会立刻提示，并提供直接跳到「设置」的入口；
保存失败时也会问你要不要现在就去改位置。

**备份机制**（自动，无需操作）：

- 每次保存都会把上一版留成 `data.json.bak` —— 所以误删后通常还能从 `.bak` 手工找回
- 若数据文件损坏无法解析，软件会把原文件改名保留为 `data.json.corrupt-<时间戳>`，然后以空数据启动并明确提示路径，**不会静默丢数据**

**手工备份**：直接复制整个 `打卡助手` 文件夹即可。数据是明文 JSON，也可以自己编辑或写脚本统计。

### 数据格式

```json
{
  "schema": 1,
  "heatmapMode": "habit",
  "habits": [
    {
      "id": "8f3c…",
      "name": "早起",
      "color": "#2F6FED",
      "createdAt": "2025-06-01",
      "order": 0,
      "entries": {
        "2025-06-01": { "mood": 4, "note": "六点半起床" },
        "2025-06-02": { "mood": null, "note": "" }
      }
    }
  ]
}
```

`entries` 里**出现该日期键就代表当天已打卡**；`mood` 取 1–5（很差→很好）或 `null`。

## 统计口径（明确定义）

设「今天」为本地日期，某习惯已打卡日期的集合为 `S`。

- **当前连续**
  - 今天 ∈ `S` → 从今天往前连续计数
  - 否则昨天 ∈ `S` → 从昨天往前连续计数（**今日宽限**：当天还没打卡不算断，避免清早打开软件就看到连续天数归零）
  - 否则 → `0`
- **最长连续**：`S` 中所有连续区段长度的最大值
- **累计打卡**：`|S|`（同一天重复打卡天然去重）
- **本月完成率**：分子 = `S` 中落在 `[max(本月1日, 创建日), 今天]` 的天数；分母 = 该区间的自然天数
- **全部习惯模式的热力深浅**：当天已打卡习惯数 ÷ 当天已创建的习惯数，映射到 4 档

## 从源码重新构建

需要源码改动后重新编译时：

```
双击 build.cmd
```

或：

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

构建脚本使用 **Windows 自带的 .NET Framework 编译器** `csc.exe`，不下载任何东西。产出：

| 文件 | 说明 |
|---|---|
| `打卡助手.exe` | 主程序（Windows 子系统，双击无控制台黑框） |
| `打卡助手-测试.exe` | 控制台版，含逻辑自测代码 |

脚本开启了 `/warnaserror+`，任何编译警告都会导致构建失败。

> **编码注意**：`build.ps1` 必须以 **UTF-8 with BOM** 保存。本机 ANSI 代码页是 936(GBK)，
> 若丢失 BOM，PowerShell 5.1 会把脚本里的中文读成乱码，从而生成文件名错误的 exe。
> `build.cmd` 则刻意保持纯 ASCII —— cmd.exe 按 ANSI 代码页解析批处理，中文放进 `.cmd` 会乱码。

## 自测与诊断

### 逻辑自测（126 项断言）

```bat
打卡助手-测试.exe --selftest
```

覆盖：连续天数与"今日宽限"、最长连续分段、完成率分母规则、闰年 2/29、跨月跨年、
热力档位边界、打卡幂等性、JSON 往返与转义、原子保存与 `.bak`、损坏文件恢复、
以及数据位置解析优先级与 `config.json` 读写。
结果同时写入 `_selftest_report.txt`（UTF-8），退出码 0 表示全部通过。

### 界面截图自检

```bat
打卡助手-测试.exe --shot 预览.png --seed 20250612
```

把真实窗口离屏渲染成 PNG 后退出（**不写入数据**）。用于在没有人工点击的情况下核对排版。
`--seed` 会生成演示数据，并额外导出 `预览.png.json`，方便用外部工具独立核对界面上的数字。

### 命令行参数

| 参数 | 说明 |
|---|---|
| `--data <路径>` | 指定数据文件（默认 `程序目录\数据\data.json`） |
| `--multi` | 允许同时开多个实例（默认单实例，重复启动会激活已有窗口） |
| `--shot <图片>` | 截图自检后退出 |
| `--seed <数字>` | 截图自检时使用可复现的演示数据 |
| `--selftest` | 运行逻辑自测（仅测试版包含） |
| `--dialog <名字>` | 截图自检时渲染对话框而非主窗口（`settings`） |
| `--help` | 显示帮助 |


## 已知限制

- **不做云同步、账号、多设备**；数据只在本机
- **不导出/导入**：数据是明文 JSON，复制文件即为备份
- **无每日提醒通知**（需要常驻后台组件）
- 绿色便携：没有安装程序，整个文件夹可以随意拷贝
- 删除习惯是**不可在软件内撤销**的永久删除（确认框会写明将丢失多少条记录），必要时靠 `data.json.bak` 手工恢复
- 为适配老编译器，源码使用 **C# 5.0** 语法：不用字符串插值、`?.`、`nameof`、自动属性初始化器与表达式体成员
